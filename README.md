# 结构动力学 · 虚拟实验室

[打开实验室](https://syzhaoln-stack.github.io/structure-motion-lab/)

面向课堂讲授的手机交互实验。教师组织讲解与交流，网页用于直接操控和观察，不设置答题或提交环节。

## 实验目录

- 00 纯弹性静力：kx＝F，拖动加载，松手保持平衡。
- 01 自由振动：位移时程、弹簧恢复力与可拖动小车。
- 02 质量与固有频率：保持刚度，比较质量对周期的影响。
- 03 正阻尼与负阻尼：观察位移、弹簧力、阻尼力和包络。
- 04 共振与力的平衡：动力放大、外力—位移关系、ma/cv/kx/F。
- 05 荷载谱到响应谱：选定单一频率，比较输入与响应的幅值和相位。

共振坐标采用手动固定量程，阻尼比可降至 0.001。动态实验保留一个开始／暂停按钮；自由振动可选择小车、桥梁或建筑外观。

## 本地使用与更新

`docs/index.html` 是完整的单文件网页，可下载后直接用浏览器打开。

可编辑源码在 `src/`。修改后在仓库根目录运行：

```sh
node build.cjs
```

无需安装 npm 依赖。生成 `docs/index.html` 后提交并推送到 `main`；GitHub Pages 从 `main` 的 `/docs` 目录发布。

网页只使用浏览器内的计算，没有服务器接口。物理模型用于课堂直观教学；三维形状是示意，并非实桥分析结果。附带的原始课程代码可在网页中展开阅读。
