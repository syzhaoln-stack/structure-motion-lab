# 结构动力学 · 虚拟实验室

[打开在线实验室](https://syzhaoln-stack.github.io/structure-motion-lab/)

v7 位移与外力版：00、01 采用真实位移 x 与外力 F；05 采用真实位移幅值谱。

面向非专业学习者的手机交互实验。教师组织讲解与交流，网页直接操作，不设置预测、答题、反思表单或解锁环节。

## 实验目录

- 00 纯弹性静力：横轴 x（cm）、纵轴外力 F（N），观察加载平衡 F=kx，松手保持外力。
- 01 动态加载：持续周期外力下的真实 x（cm）—F（N）轨迹；比较低频、固有频率和高频，观察相位差形成的椭圆。质量、刚度与外力幅值放在高级参数中。
- 02 质量与固有频率：相同刚度下，比较自由振动周期与质量的关系。
- 03 正阻尼与负阻尼：比较自由响应的收缩、保持、增长及非振荡回位。
- 04 共振与力的平衡：动力放大、方程项 ma/cv/kx 与外力 F 联动；与真实作用力的符号作区分。
- 05 荷载谱到响应谱：一次选择一个荷载频率，显示 F₀（N）到真实位移幅值 X（cm）的转换，保留完整坐标、相位与同频时程。

01 的 x 轴及 05 的位移谱使用真实厘米数值，未乘刚度，也不按当前峰值重新归一化。量程由用户手动选择；超量程只影响绘图显示，原始数值继续保留。

## 本地构建与预览

可编辑源码位于 `src/`，当前构建入口在仓库根目录：

```sh
node build.cjs
```

无需 npm 依赖。生成 `src/dist/index.html` 与 `docs/index.html`，两者都是独立 HTML，可直接用浏览器打开。仓库根目录也可以运行：

```sh
python -m http.server 8766 --bind 127.0.0.1 --directory docs
```

然后打开 [本机预览](http://127.0.0.1:8766/)。该命令仅启动本机服务，不会发布到互联网。手机端是否可见由实际预览环境决定，不能把本机 localhost 地址当成手机分享网址。

当前数学验收：01 的复数柔度、厘米单位、动力平衡、共振椭圆、每周期耗能、零输入、固定量程独立性共 16/16 项通过（432 组参数）。05数值与实际绘图12/12项通过；浏览器交互与三种手机视口54/54项通过。结果对应本版本的源码与构建文件。

## GitHub Pages 部署

GitHub Pages 从 `main` 分支的 `/docs` 目录发布。后续修改先构建和预览，再将源码与生成的 `docs/index.html` 一起提交、推送。

网页为公开静态站点，学生打开网址即可使用，无需登录。

网页只在浏览器内计算，没有服务器接口。物理模型用于课堂直观教学，结构外观是示意；原始课程代码独立保留，不随网页重构修改。
